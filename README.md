# Hero block for Moodle

The Hero block adds a full-width banner to Moodle pages, with an optional background image, title, description, course search, and up to three popular-topic links.

## ❓ About Utdanningsdirektoratet

> _Visit [udir.no](https://www.udir.no/) for more information._

_Utdanningsdirektoratet_ (The Norwegian Directorate for Education and Training) is a Norwegian government agency responsible for early childhood, primary, and secondary education. It was established on June 15, 2004, and reports to the Ministry of Education and Research.

## 🛠️ Setup and use

Install the plugin in Moodle, then add a Hero block to a supported page and edit its settings to configure the content and background image.

For a full-width hero, your Moodle site must use the Boost Union theme and have the **Outside (Top)** region activated in Boost Union options. Add the Hero block to that region.
